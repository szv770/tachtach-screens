# Feature → file map

Read `CLAUDE.md` first. Use this to jump straight to the component behind a slide type, message type, or admin section instead of grepping.

## Kiosk screen (`src/screen/`)

`App.jsx` resolves the active theme (manual, or zmanim day/night via `src/shared/dayNight.js`), wraps everything in `design/DesignRoot.jsx` (theme + font-role CSS variables, motion/graphics context) inside `ScreenScaler.jsx` (uniform scale of the 1600x900 / 900x1600 canvas), and renders `Layout.jsx` = `components/Rail.jsx` (clock, Hebrew/English date + parsha chip as one unit, weather, up-next card, side notes, credit/logo via `Credit.jsx`; or a top band in portrait) + one rounded page panel (`SlideCarousel.jsx`) + a 76 px `messages/Banner.jsx` row only when a banner is active (or the accent `messages/StageBanner.jsx` 'X just started' for a few minutes after a block starts; the rail also gets a 'Now in session' badge and, with `rail.upNextCountdown`, a live m:ss on the up-next card; see ARCHITECTURE.md Attention stages). Also `AnnouncementTakeover` (full canvas, pauses rotation), `CountdownOverlay.jsx`, `HiddenAccess.jsx` (5 taps top-left).

Design system (`src/screen/design/`): `DesignRoot.jsx` (roles + context), `globalCss.js` (@property registrations, derived roles, motion keyframes), `ui.jsx` (Panel, PageTitle, TimeText, `he()`), `fit.jsx` (auto-fit text), `Paged.jsx` (fixed-size paginated text), `graphics.jsx` (weather icons, candles, ornaments, progress ring, per-theme background art + day-phase tint), `announceStyles.js` (layout metadata for the 26 takeover styles: content insets, side-graphic box, entrance personality = **the seam for new takeover/announcement styles**; the visuals are in `src/screen/takeover/`), `fonts.js` (bundled Rubik/Manrope/Frank Ruhl/EB Garamond + uploaded `@font-face`).

Hooks: `useSSE.js`, `useSlideRotation.js` (timer only), `useAnnouncements.js`, `useClock.js`. `src/screen/lib/announcementView.js` maps announcement items to rotation slides / banner / note rows.

### Messages (`src/screen/components/messages/`) — all driven by announcements (`data/announcements.json`)

- **Takeover** (`AnnouncementTakeover` in `slides/AnnouncementSlide.jsx`) — full canvas, pauses the carousel; the stage at the real canvas size (1600x900, 16:10, or portrait 900x1600; side graphics become a top band in portrait). **26 styles** in 5 picker groups: Everyday (classic, grand, sleek, quiet, trip, mivtzoim, hype), Alerts (emergency, urgent "Important", schedule "Time change", phone "Phones away"), Moments (celebration, simcha, siyum, torah, memorial, welcome, farbrengen), Shabbos & Yom Tov (shabbos, yomtov), Seasonal (chanukah, purim, pesach, roshchodesh, lagbaomer, chassidic). Old ids keep their name (`notice` -> urgent, unknown -> classic, none -> drawn as classic). Davening style and schedule-triggered takeovers are deferred. Files in `src/screen/takeover/`: `TakeoverStage.jsx` (React: stage, `StageBox` fit/canvas, pager), `art.js` (one SVG function per style, entrance + ambient layers), `css.js` (all palettes, fonts roles, keyframes, scoped under `.tkr`), `layouts.js` (model -> HTML, `FIT` min/max table), `fit.js` (one-shot fitting, pagination, lively splitting). Content models: `src/shared/takeoverModel.js`. Per-announcement `look.animation` (full / entrance / off) x `settings.motion` -> `effectiveAnimation()`. Type: `settings.announceFonts` = editorial (default, Suez One + Playfair Display) / modern (Rubik + Manrope) / classic (Frank Ruhl Libre + Fraunces) / screen (global font roles), `ANNOUNCE_FONT_PRESETS` in `src/shared/fontRoles.js`, applied as role vars on the `.tkr` root; every text run gets `dir` from `src/shared/bidi.js`.
- **Banner** (`Banner.jsx`, rules in `src/shared/banner.js`) — bottom strip, per banner **Still** (never moves, long text shrinks to half size at most) or **Scrolling** (continuous right-to-left ticker, speed slow/normal/fast, `translate3d` only, minimal motion = still); `settings.banner.mode/speed` are the defaults. **Does not pause rotation.**
- **Notice layout** (`look.layout: 'notice'`, `content.notice { pre, focus, post (+He) }`, `layouts.js` `notice`, `.nt` in `takeover/css.js`) — small line, one BIG auto-fit focus (a name, a time), small line; what quick messages post. Big text in the style's ink for contrast in dark and light themes.
- **Board** (legacy, migrated to Classic announcement slides) — `slides/BoardSlide.jsx`.
- **Side note** — `PinnedNotes.jsx` cards in the rail, max 2 visible, more rotate every 8 s.
- **Hold** ("Pause everything else" slide) — replaces the slide area via `SlideCarousel` `hold` prop and pauses the rotation timer (`useSlideRotation(slides, { paused })`).

### Countdown (`src/screen/components/CountdownOverlay.jsx`)

Driven server-side by `src/server/countdown.js`, which schedules today's effective schedule entries (`getEffectiveSchedule`: the date's own schedule, else enabled weekly entries for today — re-init at midnight and on every schedule/date change) that have an `alertBefore` value and broadcasts SSE `countdown-start` / `countdown-tick` / `countdown-end`; the running one is also in `/api/state` as `countdown`. Display mode per entry is `countdownDisplay` (`alertDisplay` accepted as a legacy alias): `slide` replaces the slide area while it runs (SlideCarousel, like a board) or `takeover` is a full-screen overlay (App.jsx). Neither pauses the hidden rotation timer.

## Automatic Kiddush Levana (2026-10-19)

No manual input. `src/shared/kiddushLevana.js` `kiddushLevanaState(now, location, settings)` works out from the Hebrew calendar (molad arithmetic, 29d 12h 793p) and the school's lat/lon/timezone (`cache.weather.location`, `settings.location.timezone`; tzeis from fresh `cache.zmanim` `tzeit7083deg`, else computed at 7.083 degrees) the window for THIS month: starts 7 (or 3, setting) days after the molad, ends at the halfway point of the month (molad + 14d 18h 22m 1.67s; alternative 15 days after). Only at night, tzeis to dawn. Custom skips are data (`SKIP_CUSTOMS`: nights up to Tisha B'Av, Rosh Hashana to Yom Kippur skipped; Yom Kippur to Sukkos noted), default on. Display, all virtual items through `selectActive` (never in announcements.json): rail side note (moon) all day from the day the window opens until the last night ends; banner on each open night, the last night says LAST NIGHT; a 3-minute calm `torah`-style takeover on the first normal evening and on the last night, once per occasion (server writes `data/kiddush-levana.json` when it first sees the occasion open; the kiosk polls `/api/kiddush-levana/shown`); Motzei Shabbos mention on the banner/note when that night is in the window. Admin: Announce > Posts > "Kiddush Levana (automatic)" card (on/off, 3|7 days, end rule, customs, read-only this-month molad / can start / cutoff, `GET/PUT /api/kiddush-levana`, `announcements.edit` to change). **Upcoming months (follow-up):** inside the card, an 'Upcoming months' list (`announcements/KiddushLevanaMonths.jsx`): next 14 (or 24) months, each with can start / last night and a closed Details (molad, cutoff, customs notes, Edit), per-month edit sheet (own start / cutoff on the school clock, or Skip this month, Reset to computed), 'Share with the rabbi' sheet (printable page in an iframe + Copy text / Print / Download .txt, includes the rules used and the questions list). A 'Hebrew line' toggle (default off) adds Hebrew to the rail note / banner / takeover; English is always shown, and rail side notes show English first with the Hebrew line beneath (they used to show Hebrew only). Search: "kiddush levana", "molad".
